### 접근
주어진 배열에서 특정 구간을 추출하고, 이를 정렬한 뒤 원하는 위치의 숫자를 찾는 시뮬레이션 문제. commands 배열의 각 원소 [i, j, k]에 대해 순차적으로 작업을 수행하며, 문제의 순서(1번째부터 시작)와 C++ 배열의 인테스(0부터 시작) 차이를 맞추기 위해 인덱스 계산 시 -1을 해주는 것이 핵심.

### 풀이
1. commands 배열을 순회하며 각 명령어의 i, j, k 값을 추출
2. 원본 배열 array의 i-1 ~ j-1인덱스까지 반복문을 돌며 임시 배열 tmp에 원소들을 복사
3. sort() 함수를 사용하여 tmp를 오름차순으로 구현
    - 이때 cmp는 필요없음(기본적으로 오름차순 정렬)
4. 정렬된 tmp에서 k-1인덱스에 있는 값을 answer의 뒤로 추가
5. answer 반환


### 복잡도
N: array의 길이 | C: commands의 길이
- 시간 복잡도: O(C * NlogN)
    - N길이의 배열을 생성(O(N)) + 정렬(O(NlogN))
    - 이 과정을 C번 반복

- 공간 복잡도: O(N + C)
    - 구간 복사를 위한 O(N): tmp
    - 결과 저장을 위한 O(C): answer


### Code
```cpp []
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

vector<int> solution(vector<int> array, vector<vector<int>> commands) {
    vector<int> answer;
    
    for (int t1 = 0; t1 < commands.size(); t1++) {
        int i = commands[t1][0];
        int j = commands[t1][1];
        int k = commands[t1][2];
        
        vector<int> tmp;
        for (int t2 = i - 1; t2 <= j - 1; t2++) {
            tmp.push_back(array[t2]);
        }
        
        sort(tmp.begin(), tmp.end());
        answer.push_back(tmp[k - 1]);
    }
    
    return answer;
}
```
